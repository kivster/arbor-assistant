# Arbor Assistant logo

An independent tree-and-home mark for Arbor Assistant. It is not the Arbor
Education or Home Assistant logo.

The original transparent PNG is `arbor-assistant-master.png`. The integration
ships 256 px and 512 px PNG exports in
`custom_components/arbor_assistant/brand/`, following the
[Home Assistant branding format](https://contributors.home-assistant.io/core/integrations/brands/).
The same mark is used on light and dark backgrounds. HACS catalogue display
depends on HACS support for local integration branding.

Generated with the built-in image generation tool on 22 October 2026. Exports
were resized with macOS `sips`, preserving transparency. No student data or
portal screenshots were used as image inputs.

## Generation prompt

Use case: logo-brand
Asset type: square logo icon for Arbor Assistant, an independent community Home Assistant integration connecting parents with school information.
Primary request: Create one polished, distinctive logo mark. Combine a friendly stylised tree with the simple silhouette of a home in one coherent geometric symbol, suggesting learning, growth and home. Minimal flat vector-like design, confident rounded shapes, excellent silhouette and balanced negative space. Natural green foliage with a complementary blue home element. Designed to remain clear at 48 pixels. One centered symbol occupying about 80 percent of a square canvas.
Scene/backdrop: genuinely transparent background.
Constraints: no text, no letters, no gradients, no shadows, no mockup, no border, no watermark. Original mark; do not reproduce the Arbor company logo or the Home Assistant logo. Deliver a single finished icon, not a sheet of alternatives.
